# S!team2 - مستند راه‌اندازی و تست پروژه

## معرفی
این پروژه یک سامانه مدیریت و پایش پروموتر با امکانات کامل ورود، نقش‌بندی، داشبورد ادمین، ثبت فعالیت‌ها، مکان‌یابی، کنترل کیفیت، گزارش حادثه، پشتیبانی فوری و مدیریت اسپات/پروموتر است. کلیه بخش‌ها کاملاً ماژولار و قابل توسعه می‌باشند.

---

## مراحل نصب و راه‌اندازی

### 1. بارگذاری فایل‌ها
- همه پوشه‌ها و فایل‌ها را در هاست یا پوشه پروژه خود قرار دهید. ساختار رعایت شود:
  - `/pages` (برگه‌ها)
  - `/api` (پردازش و API)
  - `/assets/images`, `/assets/sounds`, `/assets/lottie` (فایل‌های چندرسانه‌ای)
  - `/vendor/leaflet`, `/vendor/lottie` (کتابخانه‌ها)
  - `/css`, `/js`
  - سایر فایل‌ها (`index.php`, `config.php`, ...)

### 2. ساخت دیتابیس
- فایل SQL موجود (`database/steam2_schema.sql`) را در phpMyAdmin یا ابزار مدیریت دیتابیس import کنید.
- لیست کامل استان/شهر را نیز در صورت نیاز ایمپورت نمایید (در صورت ناقص بودن استان/شهرها).

### 3. تنظیمات اتصال دیتابیس
- فایل `config.php` را باز کرده و مقادیر `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, `BASE_URL` را مطابق سرور خود اصلاح نمایید.

### 4. بارگذاری فایل‌های چندرسانه‌ای
- فایل‌های صوتی (`touch.mp3`, `success.mp3`, `error.mp3`) را در `assets/sounds` قرار دهید.
- انیمیشن‌های Lottie (`login.json`, `qc.json`, ...) را در `assets/lottie`.
- فونت وزیرمتن را در `assets/fonts` بگذارید یا با CDN جایگزین کنید.

### 5. ایجاد ادمین اولیه
- مستقیم در جدول `users` یک کاربر با role=`admin` و رمز هش‌شده ایجاد کنید:
  - از ابزار آنلاین [bcrypt generator](https://bcrypt-generator.com) برای هش کردن رمز استفاده کنید.
  - مثال:
    ```
    INSERT INTO users (username, password, role, active) VALUES ('admin', '$2y$10$...', 'admin', 1);
    ```
- سپس با همین کاربر وارد شوید و سایر ادمین/پروموترها را اضافه کنید.

## چک‌لیست تست پروژه

- [ ] ورود ادمین و پروموتر (اطمینان از امنیت و هدایت درست)
- [ ] افزودن پروموتر (همه فیلدها، آپلود عکس)
- [ ] ویرایش/غیرفعال‌سازی/حذف پروموتر
- [ ] افزودن اسپات با نقشه و انتخاب استان/شهر
- [ ] شروع/پایان فعالیت و چک فاصله (ثابت و گردشی)
- [ ] چک هشدار فاصله و پایان خودکار
- [ ] ثبت فرم QC با سلفی و ویدیو (اجباری بودن)
- [ ] ثبت حادثه با فایل‌های عکس/ویدیو/صوت
- [ ] ارسال درخواست پشتیبانی فوری
- [ ] نمایش پیام‌ها و صداها در تمام سناریوها
- [ ] ریسپانسیو بودن در موبایل و دسکتاپ
- [ ] دسترسی به صفحات فقط طبق نقش
- [ ] کارکرد صحیح پاپ‌آپ‌ها و UX

## نکات توسعه

- برای افزودن فیچر جدید، یک فایل جدید در `/pages` و `/api` اضافه کنید و آن را به منو یا پنل مربوطه لینک دهید.
- برای امنیت بیشتر، توصیه می‌شود توکن لاگین را به JWT یا session server تغییر دهید.
- فایل‌های آپلودی با نام یکتا و در پوشه‌های مجزا ذخیره می‌شوند.
- همه پرس‌وجوهای دیتابیس با PDO و آماده‌سازی انجام شده است.
- برای توسعه تجربه کاربری، می‌توانید از SweetAlert2 یا کتابخانه‌های UI دیگر استفاده کنید.
